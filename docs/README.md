# 文档索引

四份文档，按「你想干什么」分（正文三份＋L3 专页一份）。机制与操作分开放，是因为读者常常只要其中一份。

| 文档 | 回答什么 | 什么时候读 |
|---|---|---|
| [`../README.md`](../README.md) | 这是什么、为什么这样设计、现在跑成什么样、边界在哪 | 第一次打开这个仓库 |
| [`工作原理.md`](工作原理.md) | 它凭什么能跑：七个文件面、一次协作的生命周期、坏了会怎样 | 想知道「为什么这样做」或准备改机制 |
| [`使用指南.md`](使用指南.md) | 怎么上手：L0 环境自检＋L1／L2／L3 四条路、从零搭起来的第 0 步＋八步、常见故障 | 准备在自己工作区里搭一套 |
| [`L3-动手前必读.md`](L3-动手前必读.md) | 动插件层之前必须知道的事：八条真实事故、回滚包打头、四道闸、退出顺序 | 准备装或改 `plugins/` 之前 |

`assets/` 里是正文引用的实跑输出原文（如 `selftest.txt`），用来核对正文里的数字不是手抄的。

还没有的东西也写在这里，免得读者以为是漏了：`demos/` 下那三个真 demo（防丢信／热拔插续跑／拒绝无证据的「已修好」）在根 `README.md` 的「更新计划」里，做出来之前不占位。

- **要动 L3（插件层）**：先做回滚包（`starter/profile_backup.py` 的 `save`／`verify`／`restore --dry-run`），再读 [`L3-动手前必读.md`](L3-动手前必读.md)——回滚包打头，八条真实事故、四道闸、退出顺序。
